# Privacy Notice

## Local-first operation

The default web workspace stores task data in the current browser. The mobile starter stores task data on the device. The local CLI reads and writes files selected by the user. Local planning does not intentionally transmit task data to an AI provider.

## Optional external services

OpenAI/ChatGPT, Anthropic/Claude, Google/Gemini, calendars, cloud synchronization, and account features are optional integrations. They should only run after the user selects the service, sees what information will leave the device, and explicitly consents. Each external service has its own privacy practices.

## Data minimization

Do not enter passwords, access tokens, controlled information, employer-confidential information, private customer data, health data, financial account data, or other sensitive content unless you have authority and a secure approved environment.

## No hidden telemetry

The included starter applications do not intentionally add analytics or advertising telemetry. Contributors should disclose any future analytics, make them optional where practical, and document collection, retention, and deletion behavior.

## Your controls

Use task deletion, JSON export, CSV export, local backups, and browser/device storage controls to manage local data. Cloud account and synchronization controls must include export and deletion functions before they are enabled.
