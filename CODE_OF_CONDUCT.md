# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project welcoming and harassment-free for everyone.

## Expected behavior

Use respectful language, accept constructive feedback, focus on the work, and respect privacy and security boundaries.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, publication of private information, or knowingly submitting malicious code or secrets are not acceptable.

## Enforcement

Report concerns privately to the repository maintainer. The maintainer may remove content or restrict participation to protect participants and the project.
